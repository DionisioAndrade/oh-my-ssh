# Bundled terminal font

The unmodified Regular, Medium, and Bold TTF files are from the official [Fira Code 6.2 release](https://github.com/tonsky/FiraCode/releases/tag/6.2).

Release archive: `Fira_Code_v6.2.zip`.

SHA-256 of the original archive: `0949915ba8eb24d89fd93d10a7ff623f42830d7c5ffc3ecbf960e4ecad3e3e79`.

Copyright (c) 2014, The Fira Code Project Authors. The font is distributed under the SIL Open Font License 1.1. The [verbatim license](../LICENSE.FiraCode.txt) accompanies application output. The files are embedded as WPF resources, without installing the font on Windows or requiring network access at runtime.

Programming ligatures are a renderer option; disabling them retains the original character data and fixed terminal cell positions.
